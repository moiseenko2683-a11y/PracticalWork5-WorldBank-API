# Практична робота № 5
## Отримання та оброблення даних із вебджерел

### Мета роботи
Ознайомитися з отриманням даних із вебджерел за допомогою HTTP-запитів у Python, навчитися працювати з API, обробляти дані у форматі JSON та перетворювати їх у формат CSV.

### Завдання
Отримати дані зі Світового банку про **Exports of goods and services (% of GDP)** для всіх доступних країн і територій за 2015 та 2019 роки. Зберегти отримані дані у форматах JSON і CSV та вивести їхній вміст на екран.

### Використані технології
 Python
 Бібліотека `requests` для HTTP-запитів
 Бібліотека `json` для роботи з JSON
 Бібліотека `csv` для створення CSV-файлу
 API Світового банку

### Показник дослідження
 Назва: Exports of goods and services (% of GDP)
 Код показника: `NE.EXP.GNFS.ZS`
 Роки: 2015 і 2019
 Джерело: [World Bank API](https://api.worldbank.org/v2/country/all/indicator/NE.EXP.GNFS.ZS?date=2015:2019&format=json&per_page=20000)

### Файли проєкту
 `PythonApplication15.py` — програмний код.
 `exports_data.json` — отримані та оброблені дані у форматі JSON.
 `exports_data.csv` — дані у форматі CSV.
 `Лабораторна робота Моісеєнко5.sln` — файл рішення Visual Studio.

### Запуск програми
1. Встановити Python.
2. Встановити бібліотеку командою `python -m pip install requests`.
3. Запустити файл `PythonApplication15.py`.
4. Переглянути створені файли JSON і CSV.

### Результат
Реалізовано отримання даних через API Світового банку, їх оброблення, збереження у форматах JSON і CSV та виведення вмісту файлів на екран.

### Висновок
Під час виконання практичної роботи отримано навички роботи з HTTP-запитами, API, JSON і CSV у Python. Дані про експорт товарів і послуг у відсотках від ВВП за 2015 та 2019 роки було завантажено й збережено у файлах для подальшого використання.
